# Посмотри в окно

Проектная работа Яндекс Практикума: дописать CSS для готового приложения с видео из разных городов.

## Что внутри

- `index.html` — готовая разметка (не меняется)
- `styles/style.css` — **основной файл для доработки**
- `styles/preloader.css`, `styles/error.css`, `fonts/fonts.css` — готовые стили (не менять)
- `scripts/script.js` — готовая логика (не менять)

## Что сделано в style.css

- Лейаут на flex: центрирование `.content`, строка `.search-form`, фиксированная высота списка со скроллом.
- Размеры видео, карточек и превью через `object-fit` / `object-position`.
- Типографика: Oswald для заголовков, обрезка текста через `ellipsis` и `line-clamp`.
- Кастомные чекбоксы через `::after` + `:checked`, фокус через `:has(:focus-visible)`.
- Кнопки и карточки: состояния `:hover`, `:active`, `:focus`, `:focus-visible`.
- `position: relative` на контейнерах видео и списка — для прелоадеров и блока ошибки.

## Запуск

Открыть `index.html` в браузере. Для сверки с макетом — Pixel Perfect.
